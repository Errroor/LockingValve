## [#19](https://github.com/Errroor/LockingValve/issues/19) Создать или открыть расчетный проект и выбрать шаблон клапана

Тип: история. Приоритет: P0. Выпуск: MVP.

Родитель: [#1](https://github.com/Errroor/LockingValve/issues/1).

Спринт: 3 — Геометрия материал и проверка входов. Предварительный календарь.

Предварительная оценка: 3 условных единиц сложности. Оценки дочерних задач повторно не суммируются.

### Пользовательская история
Как инженер, я хочу создать или открыть расчетный проект и выбрать шаблон клапана, чтобы начать расчет с явно заданной структуры модели.

### Назначение и границы
Начать расчет с явно заданной структуры модели. Основание: Подготовить модель клапана — создать или открыть проект и выбрать шаблон. Функция планируется; наличие прототипа и описания не означает готовности программной реализации.

### Функциональные требования
1. Создавать новый проект с устойчивым идентификатором либо открывать сохраненные входные данные поддерживаемой версии
2. Показывать название и версию доступного шаблона
3. После выбора заполнять только параметры, имеющие источник, и явно выделять незаполненные обязательные поля
4. Указывать двумерную осесимметричную расчетную область; демонстрационные значения помечать
5. Открытие данных не запускает расчет автоматически; повтор эксперимента из проекта относится к версии 1.0

### Входные данные и единицы
Новый проект либо сохраненные входы; идентификатор и версия шаблона; параметры в мм и °C

### Выходные данные
Черновик проекта и модели со ссылкой на шаблон

### Предусловия
Создан черновик расчетного проекта.

### Основной сценарий
1. Инженер создает проект или выбирает файл входных данных
2. Система проверяет версию формата
3. Инженер выбирает шаблон для новой модели либо просматривает открытые параметры
4. Проверяет заполненные и отсутствующие параметры
5. Переходит к вводу исходных данных

### Альтернативы
При смене шаблона система запрашивает подтверждение замены уже введенных значений.

### Ошибки
Шаблон отсутствует; проект поврежден, имеет неподдерживаемую версию или неполные данные.

### Критерии приемки
1. Новый проект имеет идентификатор
2. Сохраненные входы открываются без автоматического запуска
3. Неподдерживаемая версия отклоняется с объяснением
4. Выбранный шаблон и его версия видны
5. Отсутствующие данные не подменяются нулями
6. Демонстрационный шаблон не получает отметку проверенной модели

### Требования качества
Сохранять идентификаторы и версии входов; показывать единицы и происхождение данных; не смешивать демонстрационные и вычисленные результаты. Ошибка не должна уничтожать введенные данные.

### Вопросы для уточнения
Утвердить состав единственного начального шаблона и происхождение его значений.

### Зависимости
Нет предшествующих историй.

### Технические части
Отдельное техническое разбиение пока не требуется; реализация принимается по критериям истории.
