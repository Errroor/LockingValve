# База знаний LockingValve

Продукт поддерживает решение инженера при сравнении режимов прогрева стопорного клапана. Первый выпуск использует двумерную осесимметричную тепловую модель, последовательный и MPI расчет. Прямое управление оборудованием в границы продукта не входит.

Текущая стадия — анализ требований и организация разработки. Кликабельный прототип содержит демонстрационные значения. Вычислительный сервис не подключен; наличие карточек и спецификации не подтверждает готовность решателя.
