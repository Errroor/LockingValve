# Приложение для параллельного моделирования прогрева стопорного клапана и выбора режима прогрева

Автор — Чучман Н. М., группа 1-46м. Учебный проект по дисциплине «Управление жизненным циклом ПО». Краткое имя репозитория — LockingValve.

Продукт поддерживает решение инженера при сравнении режимов прогрева стопорного клапана. Первый выпуск использует двумерную осесимметричную тепловую модель, последовательный и MPI расчет. Прямое управление оборудованием в границы продукта не входит.

Текущая стадия — анализ требований и организация разработки. Кликабельный прототип содержит демонстрационные значения. Вычислительный сервис не подключен; наличие карточек и спецификации не подтверждает готовность решателя.

## Основной путь инженера
Параметры клапана → материал и условия → сценарии и ограничения → расчет → результаты → сравнение → подтверждение решения → сохранение и CSV.

## Первый выпуск
Подготовка модели и проверка ввода; режимы и критерии; пакетный запуск; последовательный и MPI расчет; состояние задания; поле, контрольные точки и показатели; проверка ограничений; объяснимое сравнение и подтверждение инженером; сохранение исходных данных и связанных результатов; CSV.

P0 — MVP; P1 — версия 1.0; P2 — версия 2.0. Приоритет и выпуск хранятся отдельными признаками. Расширения OpenMP, кластер и температурно-зависимый справочник относятся к версии 2.0. 3D экран прототипа показывает развитие визуализации; самостоятельный 3D расчет не включен.
